# ghostos 0.2.13

Date: 2026-08-08

## Summary

This release prevents GhostOS browser initialization from invoking Lodash's
runtime type-tag probe against read-only platform objects such as `DataView`.

## Changes

- Replaced full-package Lodash imports with direct `memoize` and `throttle`
  function imports.
- Added a browser regression test that rejects full-package Lodash imports in
  the affected runtime modules.

## Compatibility Notes

- This is a backward-compatible patch release.
- There are no public API, graph schema, or runtime behavior changes.
- Downstream browser consumers should update their pinned `ghostos` version.
