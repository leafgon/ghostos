# ghostos 0.1.29

Date: 2026-07-04

## Summary

This release tightens Hermes SSE output behavior so only user chat messages are emitted to downstream RxJS subscribers, while runtime noise and heartbeat frames are suppressed.

## Changes

- Updated SSE frame dispatch filtering in `src/api/parser/nodelogic/elements/library/hermes.js`:
  - keep only `event: hermes.event` for output dispatch.
  - ignore `event: hermes.heartbeat` for output dispatch.
  - ignore `kind == "runtime.observed"` unless `payload.error` is non-null.
  - emit user chat events only when `payload.discord.eventType == "MESSAGE_CREATE"` and `payload.content.text != null`.
- Added deterministic filter diagnostics through `HERMES_TRACE event=sse.event.filtered` with reason fields for skipped frames.
- Added/updated browser tests in `src/api/parser/nodelogic/elements/library/hermes.browser.test.js` to cover:
  - runtime noise suppression.
  - runtime error pass-through.
  - non-message and null-text suppression.
  - ignored unnamed/default SSE `message` frames.

## Compatibility Notes

- This is a backward-compatible patch release.
- Integrations relying on previously forwarded non-chat runtime frames from SSE should now consume only filtered chat/error events from Hermes node output.
