# ghostos 0.1.27

Date: 2026-07-04

## Summary

This release finalizes Hermes SSE client behavior for production finite-stream patterns by tightening preflight/auth semantics and preventing false auth-failure classification during repeated no-frame reconnect attempts.

## Changes

- Updated Hermes SSE preflight probing in `src/api/parser/nodelogic/elements/library/hermes.js` to use `HEAD` with `Accept: text/event-stream`.
- Marked SSE auth as passed on successful preflight `2xx` responses (`sse.auth.pass reason=preflight_http_2xx`) in addition to stream `open`.
- Changed `readTransport: "auto"` no-frame retry threshold handling to emit lifecycle diagnostics and poll fallback without `sse.auth.fail` for `max_no_frame_retries`.
- Preserved explicit auth-failure behavior for concrete auth evidence (`401/403`) while keeping deterministic reconnect and fallback behavior for transient closures.
- Expanded Hermes browser coverage in `src/api/parser/nodelogic/elements/library/hermes.browser.test.js` to validate `HEAD` preflight, no-frame fallback behavior, and absence of false auth-fail logs on threshold fallback.

## Compatibility Notes

- This is a backward-compatible patch release.
- SSE diagnostics now better distinguish authentication failures from transient/no-frame stream behavior.
