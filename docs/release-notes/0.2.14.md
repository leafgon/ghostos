# ghostos 0.2.14

Date: 2026-08-09

## Summary

This release makes newly scaffolded LEAFlisp nodes compatible with Leaf
Server's canonical mutation contract.

## Changes

- Added `leaf.object: null` to the standard `leaflisp` scaffold.
- Added a regression test for the canonical LEAFlisp node shape.

## Compatibility Notes

- This is a backward-compatible patch release.
- Existing stored nodes are not modified.
- Graph mutation clients should update to this version before creating new
  LEAFlisp nodes against canonical-validation Leaf Server deployments.
