# ghostos 0.1.26

Date: 2026-07-04

## Summary

This release hardens Hermes SSE read behavior to correctly handle finite streams, improve auth/error classification, and provide robust reconnect and fallback behavior.

## Changes

- Updated Hermes SSE lifecycle in `src/api/parser/nodelogic/elements/library/hermes.js` to resolve auth on stream `open` and avoid misclassifying post-open closures as auth failures.
- Added SSE preflight status probe (`Accept: text/event-stream`) before opening `EventSource` to classify explicit `401/403` auth failures separately from transient upstream errors (for example `5xx`).
- Added robust reconnect behavior with deterministic jittered backoff for finite/disconnected streams that have seen activity, instead of immediate poll fallback.
- Added thresholded poll fallback for `readTransport: "auto"` after repeated no-frame SSE failures (`max_no_frame_retries`), including deterministic diagnostic logs.
- Kept and validated support for both custom server SSE event types (`hermes.event`, `hermes.heartbeat`) and default `message` frames.
- Added cross-reconnect SSE deduplication by message/event identifier to prevent duplicate downstream emissions.
- Expanded Hermes browser tests in `src/api/parser/nodelogic/elements/library/hermes.browser.test.js` to cover preflight auth handling, finite-stream reconnect behavior, no-frame fallback thresholding, default message handling, and deduplication across reconnects.

## Compatibility Notes

- This is a backward-compatible patch release.
- `readTransport: "auto"` now prefers SSE continuity and reconnect before poll fallback; poll fallback still occurs deterministically after repeated no-frame failures.
