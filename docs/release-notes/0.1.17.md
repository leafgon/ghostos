# ghostos 0.1.17

Date: 2026-06-19

## Summary

This release updates default LEAF GraphQL service endpoints to use `www.leafgon.com` and adds explicit runtime endpoint override APIs for library users.

## Changes

- Default GraphQL URIs now point to `https://www.leafgon.com/*` and `wss://www.leafgon.com/*`.
- Added endpoint override helpers:
  - `getLEAFgqlEndpoints()`
  - `setLEAFgqlEndpoints({ endpoint_subs, websocket_subs, endpoint_qm })`
- Improved `initializeLEAFlakeGQLClient({ _clientConfig })` to merge partial config with defaults, so callers can override only the fields they need.
- Exported endpoint override helpers from public entry points (`core` and browser surface).
- Updated README examples to reflect `www.leafgon.com` defaults and runtime override usage.

## Compatibility Notes

- Existing users can continue passing explicit endpoint values as before.
- Runtime endpoint overrides are module-global; for per-client isolation, prefer passing explicit endpoint/config values to each client construction call.
