# ghostos 0.2.15

Date: 2026-08-11

Related issue: https://github.com/leafgon/ghostos/issues/109

## Summary

This release preserves numeric values returned by LEAFlisp graph nodes instead
of coercing them to strings.

## Changes

- Reused the standalone LEAFlisp JavaScript-value conversion for graph-node
  output.
- Added regression coverage for scalar, vector, and nested-map numbers.

## Compatibility Notes

- This is a patch-level runtime correction with no syntax or API-shape changes.
- Consumers that relied on numeric strings from graph-node execution must now
  handle JSON numbers.
- Standalone `executeLEAFlisp` behavior is unchanged.
