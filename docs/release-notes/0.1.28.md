# ghostos 0.1.28

Date: 2026-07-04

## Summary

This release aligns Hermes SSE client behavior with finite, named-event stream semantics from leaf-server and removes false poll fallback in authenticated short-close sessions.

## Changes

- Updated Hermes SSE preflight in `src/api/parser/nodelogic/elements/library/hermes.js` to use `HEAD` and avoid consuming stream payload before `EventSource` attaches listeners.
- Added one-time preflight per stream lifecycle (`preflightAttempted`) to avoid repeated preflight churn on reconnect.
- Refined SSE error classification for authenticated no-frame closures:
  - preserves explicit auth failure only for `401/403`.
  - treats `open`/authenticated/preflight-2xx short closures as reconnectable stream completion instead of no-frame terminal failure.
- Reset SSE reconnect retry backoff on frame receipt to keep retry cadence stable after successful event delivery.
- Expanded browser coverage in `src/api/parser/nodelogic/elements/library/hermes.browser.test.js`:
  - validates `HEAD` preflight behavior.
  - verifies reconnect behavior for authenticated short no-frame closures without poll fallback.
  - preserves poll fallback behavior for repeated true no-frame/transient failures.

## Compatibility Notes

- This is a backward-compatible patch release.
- `readTransport: "auto"` now prefers SSE reconnect for authenticated finite-stream closure patterns and falls back to poll only for repeated genuine no-frame failure conditions.
