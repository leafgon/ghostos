# ghostos 0.1.31

Date: 2026-07-05

## Summary

This release fixes Hermes SSE user-message filtering so valid `discord.message.received` events with message text in `payload.content` are emitted to downstream RxJS subscribers.

## Changes

- Updated Hermes SSE event filtering in `src/api/parser/nodelogic/elements/library/hermes.js` to treat `kind == "discord.message.received"` as a valid user-message signal.
- Expanded message text extraction to support `payload.content` and additional safe content fallbacks instead of relying on a narrow shape.
- Tightened non-user suppression to explicit actor signals (`bot` / `self` / `system`) so valid user messages are not dropped as `not_user_message`.
- Added browser regression tests in `src/api/parser/nodelogic/elements/library/hermes.browser.test.js` covering:
  - dispatch for `discord.message.received` with `payload.content` text.
  - filtering when explicit bot actor flags are present.

## Compatibility Notes

- This is a backward-compatible patch release.
- Hermes output remains strict to user message/error semantics while improving compatibility with current server event payload shapes.
