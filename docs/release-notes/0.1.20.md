# ghostos 0.1.20

Date: 2026-07-03

## Summary

This release hardens Hermes write-path behavior by treating empty-input sentinel bottles as no-op inputs and preserving deterministic read/write control flow.

## Changes

- Added a Hermes pre-write guard in `src/api/parser/nodelogic/elements/library/hermes.js` for empty-input sentinels with bottle names `empty_bottle` and `empty` when content is `empty_data`, `null`, or `undefined`.
- In `mode: "write"`, Hermes now skips the write API call for empty-input sentinels and emits no write output (no error).
- In `mode: "both"`, Hermes now skips write for empty-input sentinels while still executing the read path.
- Preserved existing non-empty behavior for valid command payloads and preserved explicit upstream `error` bottle passthrough behavior.
- Added deterministic Hermes tests in `src/api/parser/nodelogic/elements/library/hermes.browser.test.js` for sentinel no-op write behavior in `write` and `both` modes, valid write invocation, and explicit error bottle handling.

## Compatibility Notes

- This is a backward-compatible patch release.
- Hermes write calls are now suppressed only for explicitly recognized empty-input sentinel bottles.
