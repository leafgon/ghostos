# ghostos 0.1.19

Date: 2026-07-03

## Summary

This release adds a first-class runtime implementation for the `hermes` `leafelement` type and includes deterministic tests for Hermes read/write behavior and error handling.

## Changes

- Added `src/api/parser/nodelogic/elements/library/hermes.js` with standard element module contract support (`props` + `cachekeys`).
- Implemented Hermes write-path execution for upstream node input payloads targeting the Hermes egress command API contract.
- Implemented Hermes read-path execution for integration event polling with cursor progression and deterministic event emission.
- Added deterministic config validation and explicit fail-fast behavior for invalid/missing required config in `reduced_lambda_obj._default`.
- Added deterministic error mapping with machine-readable fields (`code`, `message`, `status`, `details`) and secret redaction in surfaced payloads.
- Wired Hermes into the element registry in `src/api/parser/nodelogic/elements/library/index.js` (`_std_elements_lut` + cache key LUT).
- Added Hermes browser tests in `src/api/parser/nodelogic/elements/library/hermes.browser.test.js` for registry resolution, write success behavior, read flow cursor behavior, deterministic validation/config failure behavior, and deterministic API/domain error behavior with redaction.

## Compatibility Notes

- `leafelement` graphs that use `elementname: "hermes"` are now executable instead of resolving to an undefined element implementation.
- Hermes config is resolved from `reduced_lambda_obj._default`; nested alternatives are not used for this release.
