# ghostos 0.2.12

Date: 2026-08-08

## Summary

This release allows page owners to create the structural `leafelement(domain)`
node required by the user-domain binding topology.

## Changes

- Added `domain` to the editor allowlist for `leafelement` names.
- Classified domain elements as structural metadata that is valid in new graphs
  but is never dispatched to a runtime adapter.

## Compatibility Notes

- This is a backward-compatible patch release.
- Downstream editor consumers must update their pinned `ghostos` version.
