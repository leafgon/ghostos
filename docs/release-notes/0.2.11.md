# ghostos 0.2.11

Date: 2026-08-07

## Summary

This release publishes the GhostOS user-domain MVP runtime and contract changes
for downstream Piper and leaf-server consumers.

## Changes

- Added the blob element runtime contract and leaf-server blob storage adapter.
- Preserved token-related LEAF events while keeping secret-bearing values
  redacted from diagnostics.
- Returned stable GraphQL mutation envelopes and preserved mutation failures for
  callers after safe logging.
- Added canonical user-domain contract-fixture validation.

## Compatibility Notes

- This is a backward-compatible patch release.
- Downstream consumers must opt in by updating their pinned `ghostos` version.
