# ghostos 0.1.30

Date: 2026-07-05

## Summary

This release fixes Hermes SSE client filtering to correctly emit user chat messages when backend payloads are wrapped in nested envelope shapes.

## Changes

- Expanded Hermes envelope normalization in `src/api/parser/nodelogic/elements/library/hermes.js` to resolve nested wrappers across `payload`, `event`, and `data` paths with bounded depth.
- Updated Hermes runtime filtering behavior:
  - `runtime.observed` events are now suppressed only when there is no payload error and no embedded user-message payload.
  - User-message classification remains strict (`discord.eventType == "MESSAGE_CREATE"` and `content.text != null`) but now evaluates normalized embedded payloads, not only shallow top-level fields.
- Added browser regression tests in `src/api/parser/nodelogic/elements/library/hermes.browser.test.js` for:
  - wrapped user-message payload dispatch.
  - wrapped `runtime.observed` payloads containing embedded user-message events.

## Compatibility Notes

- This is a backward-compatible patch release.
- Hermes SSE output remains intentionally strict to user chat/error signal semantics while improving compatibility with wrapped backend event contracts.
